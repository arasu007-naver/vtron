STMX 시사점 (짧게)



  
이 절의 제안은 모두 검토 제안이다. STMX 제품 결정을 확정하지 않는다. STMX를 언급할 때 창업자는 김호현이다.

  
    
    
  1. (A) 브랜드 연결. ShopMy는 크리에이터에게 “브랜드 유형”을 나눠 보여 주면서도, 화면의 요율은 분배를 반영한 실수령 기준으로 통일한다(S1). STMX 크리에이터–브랜드 온보딩에서도 계약 형태와 관계없이 “크리에이터가 실제로 받는 요율” 한 가지만 보여 주는 방식을 검토할 만하다.
    2. 
    
  2. (B) 수수료 부담 주체 분리. 같은 판매라도 브랜드가 플랫폼 수수료를 따로 내면 크리에이터는 100%를 받고(S1), 제3자 네트워크 경유면 커미션에서 18%를 뗀다(S1). STMX 트래킹 링크·정산 설계에서 수수료를 “커미션에서 차감”과 “브랜드에 별도 청구” 중 어느 쪽으로 할지 먼저 정해야 정산 화면과 약관이 단순해진다.
    3. 
    
  3. (B) 정산 상태의 명시. pending 30일 → locked → 주 1회 지급이라는 상태 전이가 문서에 고정되어 있다(S2). 선행 정리에서는 지급 지연·커미션 취소에 대한 크리에이터 불만이 확인되었다(H). STMX·LOOX 게시 후 정산 화면에서 상태와 취소 사유를 처음부터 보여 주는 것을 검토 제안한다.
    4. 
    
  4. 귀속 규칙의 명문화. Edelman 논란(S5·S6)은 다중 네트워크 중복 주문에서 생겼다. 외부 제휴와 함께 쓸 경우 last-click 원칙과 예외를 약관에 적어 두는 것을 검토 제안한다.
    5. 
    
  5. 약관 주의. 선행 조사는 ShopMy 약관상 ShopMy 커미션을 다른 플랫폼의 보상·캐시백 재원으로 쓰면 안 된다는 점을 주의 사항으로 적었다. 이번에는 https://shopmy.us/legal/terms-of-service를 다시 열지 않았으므로 원문 인용은 하지 않는다 선행·미재확인.
    6.
