# 환경변수명 목록 env_keys.txt 추가 — stmx-biz

## 배경과 목적
프로젝트가 사용하는 환경변수의 이름을 한곳에서 확인할 수 있도록 저장소 루트(`vtron/`)에 `env_keys.txt`를 만듭니다. 현재 이 파일은 없고, 환경변수는 Next.js 코드, scripts, `services/product-crop`(Python), Dockerfile, git에서 제외된 `.env.local`/`.env.docker`에 흩어져 있습니다.

## 범위
### 하는 것
- 저장소 루트에 `env_keys.txt`를 새로 만들고 커밋합니다.
- 아래 추출 대상의 환경변수명을 합쳐 기입합니다.

### 하지 않는 것
- 환경변수의 값, 설명, 사용 위치, 필수 여부를 기입하지 않습니다.
- `.env*` 파일과 애플리케이션 코드를 수정하지 않습니다.
- 환경변수 이름 변경, 미사용 변수 정리, 자동 생성 스크립트나 CI 검사 추가를 하지 않습니다.
- 다른 프로젝트의 환경변수를 이 파일에 넣지 않습니다.

## 변경할 동작
런타임 동작 변경은 없습니다. 파일 형식은 다음과 같습니다.
- 한 줄에 이름 하나, 값과 `=` 없음, 주석과 빈 줄 없음, 파일 끝 개행 1개
- 중복 없음, `LC_ALL=C sort -u` 순서

추출 대상(git 추적 파일, `node_modules`, `.next`, `dist`, `build`, 가상환경 제외, `*.md` 제외):
1. JS/TS/MJS의 `process.env.NAME`, `process.env["NAME"]`, `process.env['NAME']`, `process.env[`NAME`]`, 구조 분해 `const { NAME } = process.env`
2. 동적 접근의 실제 키: `files/execute-migration.js`의 `PROD_DB_URL`, `TEST_DB_URL`, `DEMO_DB_URL`
3. Python의 `os.environ`, `os.getenv` (`services/product-crop/config.py`)
4. `Dockerfile`의 `ARG`, `ENV` 이름
5. `services/product-crop/.env.example`의 키
6. 아래 '필수 포함 키'. `.env.local`/`.env.docker`는 git에서 제외되어 작업 환경에 없을 수 있으므로 이 목록을 기준으로 합니다.

필수 포함 키:
`API_KEY`, `AZURE_ACCOUNT`, `AZURE_BLOB_CONNECTION_STRING`, `AZURE_CONTAINER`, `AZURE_CONTAINER_NAME`, `AZURE_KEY`, `AZURE_STORAGE_CONNECTION_STRING`, `CDP_URL`, `CF_STREAM_ACCOUNT_ID`, `CF_STREAM_API_TOKEN`, `CLAUDE_API_KEY`, `DEMO_DB_URL`, `DOCKER_STMX_ACCESS_TOKEN`, `DOCKER_USER`, `FASHN_API_KEY`, `GEMINI_API_KEY`, `JWT_SECRET`, `MAX_ITEMS_PER_REQUEST`, `NAVER_COMMERCE_CLIENT_ID`, `NAVER_COMMERCE_CLIENT_SECRET`, `NEXT_PUBLIC_KAKAO_KEY`, `NEXT_PUBLIC_NAVER_LOGIN_CLIENT_ID`, `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `NEXT_PUBLIC_SUPABASE_URL`, `PROD_DB_URL`, `STOP_ON_BLOCK`, `SUPABASE_BUCKET`, `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_TABLE`, `SUPABASE_URL`, `TEST_DB_URL`, `TIMEOUT_MS`, `TYPESAFE_API_KEY`, `VIEWPORT_HEIGHT`, `VIEWPORT_WIDTH`, `WAIT_MS`

## 수용 기준
- 저장소 루트에 `env_keys.txt`가 있고 git으로 추적됩니다.
- 모든 줄이 정규식 `^[A-Za-z_][A-Za-z0-9_]*$`에 맞습니다.
- `LC_ALL=C sort -u -c env_keys.txt`가 종료 코드 0으로 끝납니다.
- 위 '필수 포함 키'가 모두 들어 있습니다.
- `git grep -hoE "process\.env\.[A-Za-z_][A-Za-z0-9_]*" -- ':!*.md'`로 나온 모든 이름이 들어 있습니다.
- `services/product-crop/config.py`가 읽는 모든 환경변수명과 `Dockerfile`의 모든 `ARG`, `ENV` 이름이 들어 있습니다.
- 이 변경의 diff는 `env_keys.txt` 추가 하나뿐입니다.

## 가정
- 파일 위치는 프로젝트 저장소 루트이며 프로젝트별로 하나씩 둡니다.
- 값이 없는 이름 목록이므로 git에 커밋합니다.
- `NODE_ENV`처럼 플랫폼이 제공하는 변수도 코드에서 참조하면 포함합니다.
- 문서(`*.md`)에만 언급된 이름은 실제 사용으로 보지 않아 제외합니다.
