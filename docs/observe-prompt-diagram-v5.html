G1

대상 의복 고르기 — GARMENT TARGET SELECTION

모델

G2

파라미터 읽기 — 적용성 · 값 도메인

G3

상태 — OBSERVED · ABSENT · NOT_VISIBLE · UNKNOWN

값 도메인에 None 이 있는 파라미터는 "보고 없음을 확인"하면 ABSENT 가 아니라 OBSERVED + "None"(SV-5). 증거가 값을 부정하면 안 됩니다.

G4

영역 · LOCATION · COVERAGE · POCKET

REGIONS

whole_garment | upper | lower — fit · length · fabric_behavior 는 카테고리마다 영역이 다릅니다.

LOCATION · COVERAGE

material · surface · decorative_detail · attachment 값에 부위(Body · Sleeve …)와 덮는 범위를 선택적으로 붙입니다. coverage 는 정해진 값에만.

POCKET

None/Present → construction(Inset · Applied) · projection(Flat · Projected · Volumetric). 플랩만으로 추론 금지.

관찰 규율 — 과잉 판독 금지

OBSERVATION DISCIPLINE

구조가 실제로 보일 때만 특징으로 보고합니다. surface 의 finish_realization · treated_surface_realization, pattern 의 visual_dominance 같은 강도 표시는 V2 엔진(EI · DM)이 직접 읽는 관찰값입니다.

STAGE 2 · B

descriptor — 시각 재구성

TARGET DESCRIPTOR

열거 필드가 못 담는 모양만 씁니다(descriptor_need · reconstruction_gaps RG-1…6). 같은 카테고리가 둘 이상이면 호출 ②의 색상 요청문이 이 글로 대상을 가리킵니다.

STAGE 2 · C

디자인 디테일 증거 — DM 층

DM DESIGNED DETAIL OBSERVATION

dm_designed_detail_evidence — 37개 파라미터 밖, observations 의 형제. 디자인 시스템 하나 = evidence_family + relative_size · contrast · spatial_position. DM V2 엔진의 유일한 증거입니다.

STAGE 2 · D

직렬화 JSON — SINGLE · MULTI

OUTPUT

MULTI 다섯(material · surface · decorative_detail · attachment · exposure_opening)은 values[] 에, 나머지는 scalar value. MULTI 에 "None" 금지 — 전부 없으면 ABSENT.

STAGE 2 · E

완결성 — CONTRACT SELF-CHECK

⛔ 자기 점검

적용 안 되는 키를 냈는가 · 필요한 키를 뺐는가 · 증거와 값이 어긋나는가 … 실제 거절 사례 목록으로 반환 전에 다시 봅니다.

v5 프롬프트 절 요약

절 제목은 프롬프트의 제목 그대로입니다 — 누르면 /prompt-dbg 오른쪽 원문이 그 절로 갑니다.

[SYSTEM]

  • 의복 단위 관찰자. 스타일 · 조화 · 점수 · 축(SR/TC/DM/EI) 금지, 정규 어휘만, 증거는 짧은 시각 단서

[CANONICAL CATEGORIES — choose EXACTLY ONE token per garment]

  • 10개 토큰 중 하나, 대소문자 그대로. 한 특징으로 정하지 않는다(CATEGORY SYNTHESIS DISCIPLINE)

[GARMENT TARGET SELECTION — GARMENT items only]

  • 의복만 대상. identity(C2) · readability(C3) · prominence 를 보고 — 적격은 엔진이 정함

[STATES — use the correct one; never invent a value to avoid UNKNOWN]

  • OBSERVED · ABSENT · NOT_VISIBLE · UNKNOWN. 가림은 NOT_VISIBLE, 모호함은 UNKNOWN, 증거-값 일치

[SEMANTIC `None` — WHICH PARAMETERS REQUIRE IT (SV-5)]

  • 도메인에 None 이 있는 파라미터는 확인한 부재를 OBSERVED + "None" 으로

[REGIONS]

  • whole_garment | upper | lower — rib_hem 은 upper, fit · length · fabric_behavior 는 카테고리별
