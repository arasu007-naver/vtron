/style-ex 파이프라인 구조 및 1건당 실측 토큰

STMX의 /style-ex 파이프라인은 의류 사진 1장으로부터 4글자 스타일 코드(예: ICSM, ETSD)를 추출하기 위해 관찰(Vision VLM) → 스코어링 → 판정의 과정을 수행합니다. 현재 배포 버전은 판정을 로컬 TypeScript 엔진과 규칙 판정표(tc-rules.ts)로 처리하여 판정 외부 API 비용이 $0으로 최적화되어 있습니다.

STEP ②

▼
STEP ③
판정 (TC Rules & Judge) — 4글자 코드 확정 코드 규칙 판정 ($0)
• 규칙 기반: tc-rules.ts로 TC(트렌디↔클래식) 판정 및 미결 축 기본값 확정 • (참고) LLM 판정 사용 시: 판정 프롬프트 14k 토큰 + 사고 토큰 5k 추가 소요

상품 10,000개 연산 소요 시간 및 처리율 벤치마크 (Gemini 3.8 포함)

10,000개 상품 연산은 총 3,300만 토큰의 대용량 텍스트 생성을 수반합니다. Gemini 3.8 Flash는 향상된 고속 추론 커널과 시각 처리 엔진을 통해 1건당 10~13초, 병렬 풀 가동 시 1시간 이내(약 50분~1시간 10분)에 10,000건 전체 연산을 완료할 수 있습니다.

⚡ Gemini 3.8 처리 속도 분석
Gemini 3.8 Flash는 68,068 토큰 관찰 프롬프트에 Context Caching 적용 시 TTFT 0.4초대, 생성 속도 초당 250+ 토큰을 유지합니다. 현재 기본 설정으로 심층 추론(Thinking ON)을 가동하여 시각적 모호성이 있는 의복 디테일까지 정밀 검토하며, 최대 65,536 출력 한도를 확보하여 사고 과정과 전체 JSON envelope가 완벽히 보존됩니다. (필요 시 환경변수로 초고속 Thinking OFF 전환 지원). 동시 30~50개 비동기 워커 가동 시 약 1시간 ~ 1시간 50분에 10,000건 전체 연산을 안정적으로 완료할 수 있습니다.

3사 심층 평가 및 엔지니어링 구현 가이드

Google Gemini 3.8 / 1.5 초가성비 • 최고속 (1순위)

  • 차세대 성능: Gemini 3.8 Flash는 향상된 비전 추론과 초당 250+ 토큰 생성으로 1건당 10~13초 완료.
  • 압도적 캐시 단가: 68k 프롬프트 캐시 읽기 $0.01875/1M (Opus 대비 1/270). 10,000건 비용 1.7만~3.2만 원.
  • 적합한 경우: 1만~10만 단위 대규모 이커머스 카탈로그 실시간 및 배치 추출 전체.

Anthropic Claude 고정밀 • 프리미엄

  • 강점: 미세한 봉제선, 텍스처, 실루엣 추론 정확도가 가장 우수함. 지시 불이행률 1% 미만.
  • 약점: 68k 프롬프트 캐시 읽기 단가($0.30~$0.50)가 높아 10,000건 시 비용 부담(49만~163만 원).
  • 적합한 경우: 카탈로그 메인 플래그십 의류, 고가 명품 의류의 정밀 재검증 단계.

Alibaba Qwen 동아시아 패션 특화

  • 강점: 타오바오/동대문/아시아 의류 쇼핑몰 이미지 데이터셋 학습량이 방대하여 K-패션 인식 우수.
  • 비용: 10,000건 기준 3.5만~6.9만 원으로 Gemini에 근접하는 훌륭한 가성비.
  • 적합한 경우: 국내 및 동아시아 도매 사입 의류 대량 처리, 멀티 클라우드 페일오버.

• 대규모 10,000벌 배치 추출 아키텍처 및 체크리스트

1 Context Caching 등록

68,068 토큰 관찰 프롬프트를 Gemini cachedContents.create로 사전 등록하여 네트워크 페이로드 90% 절감 및 TTFT 단축.

2 이미지 전달 최적화

이미지 파일을 Base64 문자열로 본문에 인코딩하지 않고, Supabase 스토리지 또는 웹 CDN의 Public URL을 전달하여 대역폭 병목 방지.

3 Bulk DB Insert

Gemini 3.8이 반환한 37개 파라미터 JSON을 로컬 scoring.ts에 통과시켜 Style ID 도출 후, PostgreSQL product_style 테이블에 1,000건 단위 벌크 삽입.

☆ 엔지니어링 최종 결론 및 권장 방안 (Recommended Next Step)

10,000벌 의상 Style ID 대량 산출에는 Google Gemini 3.8 Flash + Context Caching (또는 Batch API) 조합을 채택할 것을 강력 권장합니다.
• 비용 절감: 기존 Claude Opus 정가 592만 원 대비 약 1.7만 ~ 3.2만 원으로 99.5% 비용 절감 달성.
• 소요 시간: 병렬 워커 풀 가동 시 약 50분 ~ 1시간 10분 내외에 10,000건 전체 추출 및 DB 적재 완료 가능.
• 대안: 동아시아/국내 쇼핑몰 의류 특화 인식이 요구될 경우 Qwen-VL-Plus (약 3.5만~6.9만 원, 2.5~3시간 소요)를 2순위로 추천합니다.
