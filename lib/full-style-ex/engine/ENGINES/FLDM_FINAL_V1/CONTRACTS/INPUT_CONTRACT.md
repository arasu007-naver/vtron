# Input contract — FLDM_FINAL_V1

One frozen Full-Look Vision Evidence Packet produced by the Frozen Full-Look Vision Extractor Final V1 (DM Vision Evidence Transport V2, `dm_evidence.transport_contract = STMX_FULL_LOOK_DM_VISION_EVIDENCE_TRANSPORT_V2`). The adapter reads only `look_frame`, `component_registry[].component_ref / object_identity`, `dm_evidence.look_components`, `dm_evidence.look_detail_systems`, `dm_evidence.dm_evidence_visibility`. Any other field (relations, ownership, material, closure, Colour V1, Item facts, request trace) is ignored. Missing / UNKNOWN primitives contribute nothing. Technical input failures: packet absent or not an object · not a Full-Look packet · DM block absent · transport contract not V2 · systems not an array · DMP-3 `not_adjudicable:{image_failure | not_a_worn_look}`.
