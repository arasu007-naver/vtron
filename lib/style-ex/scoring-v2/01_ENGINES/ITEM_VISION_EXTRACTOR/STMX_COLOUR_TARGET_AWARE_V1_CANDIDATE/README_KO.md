# STMX Colour V1 — 대상 지정 색상 수집 후속 버전 V1 (후보)

**상태:** 후보(CANDIDATE)입니다. 오프라인 검증만 했습니다. 운영·동결이 아니며, 실사진 정확도는 확인되지 않았습니다(G53 유지).

## 무엇을 하나

기존 Colour V1 단독 호출은 사진에서 "가장 눈에 띄는 옷 한 벌"의 색만 읽고, 그 색이 어느 옷의 것인지 표시하지 않습니다. 이 후속 버전은 다음 세 가지를 합니다.

1. Item Vision V1.3 결과에서, 이미 정해진 채점 단위(옷 한 벌 · 수트 두 벌 · 여러 벌)의 대상 목록(manifest)을 만듭니다.
2. 그 대상들만 지정해서 색을 읽도록 요청문을 만듭니다(한 번에 모두 / 대상마다 따로).
3. 응답이나 저장된 색을 대상 id별로 검증해 하나의 색상 패킷으로 묶습니다.

## 바꾸지 않은 것

- Colour V1 모듈(`run/color_recovery/color_contract_v1.js`)은 해시를 확인한 뒤 읽기만 합니다. 색 계열·명도·사용·효과 같은 값의 뜻은 바꾸지 않았습니다.
- 모든 색 관측은 동결된 Colour V1 검증기로 검사합니다.
- Item Vision V1.3과 채점 엔진은 건드리지 않았습니다.

## 하지 않는 것

- 외부 호출을 하지 않습니다. 기본 전송 함수는 G53 때문에 거부합니다.
- 배열 순서로 짝짓지 않습니다. 다른 옷의 색을 옮기지 않고, 정답(GT)을 읽지 않습니다.

## 실행 (오프라인)

```
node tests/run_all.js
node verify_identity.js
```

## 복원·되돌리기

- 복원 캡슐은 이 디렉터리와 동결 Colour V1 모듈 사본(같은 상대 경로)을 함께 담습니다. 캡슐 안의 `restore.js`로 짧은 경로에 복원합니다.
- 되돌리기: 이 디렉터리를 쓰지 않으면 됩니다. 기존 Colour V1과 R3는 그대로이므로 다른 파일을 고칠 필요가 없습니다.
