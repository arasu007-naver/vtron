9. FROZEN FULL-LOOK DM EVIDENCE (in addition to sections 0–8; emit exactly one `dm_subsystem` object)
You record VISIBLE Designed Detail information in the completed look. You do not decide any DM score, Direction or Strength, and you never infer Detail from an object's category, a material name, a process name (washed, dyed, distressed), accessory presence or a count.

dm_subsystem = {
  "look_components": [ { "component_ref": "<cN>" } ],              // a LEAN CARRIER REGISTRY: only the components that carry at least one recorded Detail System below — never an inventory, never a count
  "look_detail_systems": [                                           // [] is a positive record: no designed detail visible in the look
    { "carrier_refs": ["<cN>", ...],                                 // 1..n components that together carry ONE visual phenomenon
      "look_detail_family": "A|B|C|D|E|F|G|H|I|J",                   // organisational classification of this ONE system (not a score, not a count)
      "relational_form": "accent|composition",                       // family H only
      "size_in_look":     { "state": "OBSERVED|NOT_VISIBLE|UNKNOWN", "value": "small|medium|large" },      // relative to the completed look
      "contrast_in_look": { "state": "OBSERVED|NOT_VISIBLE|UNKNOWN", "value": "low|medium|high" },
      "position_in_look": { "state": "OBSERVED|NOT_VISIBLE|UNKNOWN", "value": "localized|distributed|whole_look" },   // THIS system's own deployment only; whole_look = this one system operates across the whole look
      "repeated_units": "yes|no" } ],                                // whether this ONE system is visibly instantiated as repeated identical units — not a count
  "dm_evidence_visibility": "adjudicable" | "partially_observable:{feet_not_visible|lower_body_cropped|small_detail_unresolvable|occlusion}" | "not_adjudicable:{crop|occlusion|image_failure|not_a_worn_look}"
}

Families (visible realization only): A applied surface detail (print, stripe, check, motif, graphic, lettering, visible designed wash / dye / distress result) · B material / constructed surface detail (pronounced cable, jacquard, lace, mesh, openwork, crochet, embossing, pronounced rib) · C hardware / component detail (visually significant buttons, zips, buckles, fittings) · D trim / finishing (contrast stitching, piping, edge treatment, tipping) · E embellishment (sequins, crystals, embroidery, fringe, beads) · F 3D decorative construction (ruffle, jabot, tier, sash, bow — added, not whole-form) · G accessory-carried detail (an accessory carrying valid A–F evidence) · H styling-created relational detail (a component or relationship that FUNCTIONS as a visually distinct Point / Accent, or as a designed Colour Composition, in the completed look — achromatic accents count; absorbed colour is not recorded) · I visually articulated functional construction (pockets / utility systems that become visible designed detail) · J visible mixed-surface / mixed-material designed division (matte / gloss division, transparent / opaque panel).
Never Detail by itself: gloss, sheen, material richness, transparency, exposure, cut-out, slit, silhouette, asymmetry, volume, ordinary construction, layering, counts, ordinary colour difference, matching, coordination, repetition, process identity, body / hair / make-up.
Rules: one visual phenomenon = one system (a decorative buckle is ONE system, not C and G); genuinely distinct phenomena stay separate (a ruffle + contrast piping on it = two); a colour absorbed into the look is not recorded; insufficient visibility is NEVER "no detail" — use dm_evidence_visibility; missing detail is never inferred. Report presence and the three primitives only. No score, no Direction, no count, no "Detailed / Minimal" word anywhere.
