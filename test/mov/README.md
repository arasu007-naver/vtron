# `/mov` 검증 스위트

브라우저를 띄워 `/mov` (Portrait Studio) 를 실제로 렌더하고 픽셀을 재서 검사합니다.
`style-ID-movie-studio/test/run.mjs` 를 이식한 것으로, 검사 내용은 원본과 같고
대상만 `file://` 단일 HTML → 실행 중인 Next 서버의 `/mov` 로 바뀌었습니다.

## 실행

`/mov` 는 세션 가드(`proxy.ts`) 뒤에 있으므로 **로그인한 상태의 서버**가 필요합니다.

```bash
npm run dev
```

다른 탭에서:

```bash
cd test/mov
npm install      # 최초 1회
npm test
```

Playwright 가 크로미움을 못 찾으면 **시스템에 설치된 Chrome 으로 자동 전환**되므로,
브라우저 다운로드가 실패해도 그냥 돌아갑니다.

```bash
npm test                                   # http://localhost:8920/mov
npm run test:headed                        # 브라우저를 띄워서 눈으로 확인
node run.mjs --url=http://localhost:3000/mov   # 대상 주소 지정 (env MOV_URL 도 됨)
node run.mjs --only=bg                     # 한 그룹만 (bg pose fx region same settings guide record markup)
```

리다이렉트로 `/login` 에 도착하면 스위트가 그 사실을 알리고 멈춥니다 — 세션 쿠키가
있는 브라우저 프로필이 아니라 새 컨텍스트로 열기 때문에, 세션 가드를 통과할 수 있는
환경(로그인된 개발 서버 또는 가드가 없는 대상)에서 돌려야 합니다.

## 무엇을 검사하는가

| 그룹 | 항목 | 왜 |
|---|---|---|
| `bg` | 배경 24종 — **이음매**와 **움직임** | 예전에 미리보기는 화려한데 저장 영상만 정지 화면이었다. 24개 중 13개가 4초간 평균 3/255 미만이었음 |
| `pose` | 등장 20종 — `poseAt(1)` 이 정지 포즈와 일치 | 어긋나면 애니메이션 끝에서 캐릭터가 튄다 |
| `fx` | 화면 효과 12종 — 실제로 화면을 바꾸는가 | 세기·합성 실수로 아무것도 안 하는 효과가 생기기 쉽다 |
| `region` | 부분 효과 — 영역 **밖이 0% 불변**, 40×40 격자 스냅 | 마스크가 새면 화면 전체가 바뀐다 |
| `same` | 미리보기 == 내보내기 **픽셀 차이 0** | 이 프로젝트의 핵심 불변식 |
| `settings` | 새로고침 후 복원, collect→apply→collect 왕복 | 필드를 추가하고 저장 목록에 빼먹기 쉽다 |
| `record` | 실제 webm 생성, fps, 캐릭터 없이 저장 | |
| `guide` | 대화식 가이드 — 분기, 자동 진행, 강조 애니메이션, **강조 대상이 실제로 보이는가** | `display:none` 인 요소(파일 input)를 강조해 테두리가 안 보이던 버그를 잡았다 |
| `markup` | **이식 전용** — 모듈이 `$("id")` 로 찾는 108개 id 가 페이지에 다 있는가, 스코프된 CSS 가 Tailwind preflight 를 이기는가 | 로직(`lib/mov/portrait-studio.js`)과 마크업(`app/mov/page.tsx`)이 갈라져 있어, JSX 로 옮기며 엘리먼트를 빠뜨리면 그 기능만 조용히 죽는다 |

원본의 `build` 그룹(단일 HTML 인라인 동기화)은 이식본에 해당하는 빌드가 없어
`markup` 으로 대체했습니다.

## 알려진 실패

**`디지털 레인` — 이음매 1.33 / 움직임 4.15.** 이식 때문이 아니라 원본
(`style-ID-movie-studio`)에서도 **같은 수치로 실패**합니다. 원본 스위트를
그대로 돌려 확인했습니다. 다른 92개 항목은 통과합니다.

## 측정 함정 (두 번 걸렸던 것)

**① 움직임 검사에서 위상 한 쌍만 비교하면 안 된다.**
`t=0` vs `t=0.5` 만 보면 sin 이 우연히 같아지는 배경(선셋·더스크)과 하위 주기를 가진
배경(링 펄스 = 1/4, 신스웨이브 = 1/2)이 **정지로 오판**된다. 여러 위상의 최댓값을 쓴다.

**② 평균 픽셀차는 성긴 모션을 과소평가한다.**
비·눈·별처럼 얇고 드문 요소는 평균차가 낮게 나온다. 영상 프레임을 직접 볼 때는
평균차 대신 **12/255 이상 변한 픽셀 비율**로 판정할 것.

## 새 기능을 추가했다면

- 배경을 추가 → `bg` 가 자동으로 잡는다. 위상 규약(`Math.sin(t*TAU*정수)`, `wrap(t*정수)`)을 지켜야 통과한다.
- 등장 애니메이션 추가 → `pose` 가 자동.  회전을 건드리는 case 는 `state.rot +` 를 빠뜨리지 말 것.
- 화면 효과 추가 → `fx` 가 자동.
- 상태 필드 추가 → `collectSettings()` / `applySettings()` 양쪽에 넣어야 `settings` 가 통과한다.
- **엘리먼트를 추가** → `app/mov/page.tsx` 의 JSX 와 모듈의 `$("id")` 양쪽을 맞춰야 `markup` 이 통과한다.
- 스위트가 페이지 스코프에서 쓰는 내부 함수(`state`, `paintBg`, `setRegion` …)는
  모듈 끝의 `exposed` 목록을 통해 `window` 에 올라간다. 새로 필요해지면 거기에 추가한다.
